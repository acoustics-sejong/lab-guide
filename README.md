# 연구실 공통 안내

세종대학교 AI로봇학과 지능형 음향 및 센싱 연구실(GitHub 조직 `acoustics-sejong`) 학생을 위한 공통 안내 문서입니다. 프로젝트별 규칙(데이터 위치, 실험 기록, 담당 팀)은 각 프로젝트 저장소의 README와 CONTRIBUTING을 따릅니다.

| 문서 | 대상 |
|---|---|
| [Git·GitHub 처음 쓰는 학생을 위한 안내](git-guide.md) | Git을 처음 쓰는 모든 학생. 설치부터 첫 Pull Request, 자주 겪는 오류까지 |
| [Colab·Gemini로 작업할 때의 GitHub 관리](colab-guide.md) | Google Colab에서 노트북으로 작업하는 학생 |

## 처음 참여하는 학생

1. [GitHub Skills: Introduction to GitHub](https://github.com/skills/introduction-to-github) 실습으로 branch·commit·Pull Request를 한 번 경험합니다.
2. [Git 안내](git-guide.md) 1~4절을 따라 계정, 설치, 저장소 받기를 마칩니다. Colab에서만 작업한다면 [Colab 안내](colab-guide.md) 1절로 대신합니다.
3. 참여하는 프로젝트 저장소의 README와 CONTRIBUTING을 읽습니다.

## 이 저장소에 대하여

이 저장소는 공개(public)되어 있습니다. 내부 데이터 경로, SharePoint·MS Teams 링크, 미공개 연구 내용은 여기에 쓰지 않고 각 프로젝트의 비공개 저장소에 둡니다.

문서에서 잘못되거나 오래된 내용을 발견하면 이슈로 알려 주세요.
